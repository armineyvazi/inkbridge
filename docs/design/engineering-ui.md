# Engineering UI (planned)

- **Mac:** the existing adaptive toolbar gains an **Engineering** group:
  - a searchable component popover;
  - a connector tool (straight / orthogonal / curved);
  - an inspector panel for the selected object (label, kind, properties, style);
  - alignment buttons;
  - templates.
  It stays out of the bar until Studio Canvas or Engineering is active.
- **BOOX:**
  - one "Engineering" panel with large component tiles (glyph + name);
  - a connector mode: tap source, then target;
  - on-screen alignment;
  - text entry through the system keyboard.
  The panel is monochrome and needs no drag precision.
- **Built (Mac):** toolbar Engineering button (⌃⌥G) → Studio Canvas with engineering paper plus a floating **Engineering panel** on the right: Select/Connect, connector kind and route, inspector, align/distribute, Duplicate/Delete, searchable component grid, Templates menu. **Tablet:** read-only preview. See [../engineering/engineering-workspace.md](../engineering/engineering-workspace.md).

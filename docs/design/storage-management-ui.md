# Storage management UI

## Mac: Projects & Storage (⌃⌥J, the menu bar, toolbar •••, Settings)

- **Projects folder:** path, **Change Location…** (native folder picker → validated → Move / Leave / Cancel), Show in Finder.
- **Exports go to:** a chosen folder or "Ask each time", with Change… and Ask Each Time.
- **Now editing:** project › editable session name, Save Now, New Session.
- **Status** (Saved hh:mm · Saving… · Unsaved changes · Save failed: reason · Nothing to save yet) and free space.
- **Projects list:** search, context menu (Open, Rename, Duplicate, Show in Finder, Move to Trash… with confirmation), create.
- **Sessions of the selected project:** search, date, stroke count, Open.
- **Toolbar save glyph:** ✓ saved, ↻ saving, ● unsaved, ⚠ failed, 📄 new. Hovering shows the detail.

## BOOX: Saving card (Home) and the Projects & storage screen

- Project › session, "On your Mac: ~/Documents/InkBridge/Projects/…" (labelled as a Mac location), status, last saved, and **"On this tablet: N strokes waiting to send"** (local, kept separate).
- Save now, New session, switch project, create project, and choose among storage folders the Mac has used. The tablet can't add new Mac folders; the Mac's picker does that.
- Offline: actions are disabled, with an explanation; "Offline — Mac status unknown" (never a stale "Saved"). While a request is outstanding: "Asked your Mac…".

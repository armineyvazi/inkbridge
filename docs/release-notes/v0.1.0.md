# InkBridge v0.1.0 — first public developer preview

**Tag:** `v0.1.0` · **Date:** 2026-11-02 · **License:** MIT

## What this release is

InkBridge turns a BOOX e-ink tablet into a pen tablet for macOS: write on the tablet, and strokes appear as native vector ink over whatever is on the Mac screen. This is the first tagged public release. Internal milestones (protocol v2/v3, journal, engineering, pen controls) are folded into **0.1.0** as the baseline for external contributors.

## Supported / verified

| Area | Status |
|------|--------|
| macOS 13+ host app | Implemented; developed on recent macOS |
| BOOX Note Air 2 Plus (Android 11) over USB | **Verified (hardware)** |
| Wi-Fi TLS pairing + reconnect | Implemented; verified on hardware with probe and real app flows |
| Note Air 3 | Pending (not available during development) |
| AOA USB without developer mode | Planned (capability confirmed; transport not built) |

## Highlights

- Shared infinite canvas and document sync (Mac owns the document).
- Wi-Fi first: Bonjour, pinned TLS certificate, one-time code, device tokens.
- Tablet pen-size controls; sizes in canvas px shared with the Mac toolbar.
- Daily Journal, Engineering diagrams, Studio backgrounds, Projects & export.
- Workspace lifecycle guards (ADR-010) so Overlay / Studio / Engineering / Journal do not leave contradictory window states.

## Install (developers)

```bash
git clone https://github.com/armineyvazi/inkbridge.git
cd inkbridge
make test
make install-macos
# on a device with USB debugging:
make install-android
```

See [docs/implementation/setup.md](../implementation/setup.md).

## Artifacts

CI validates tests and builds. Signed App Store / Play Store packages are **not** part of this release (ad-hoc macOS signing; debug Android APK). Install from source with `make install-macos` / `make install-android`.

## Honest limitations

Listed in the [CHANGELOG](../../CHANGELOG.md) and [README](../../README.md). Do not treat this as a consumer App Store product yet.
